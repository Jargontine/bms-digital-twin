# BMS-Digital-Twin
This work presents a Python-based digital twin framework for lithium-ion battery management systems (BMS) targeting electric-vehicle applications. The framework integrates a first-order Thévenin equivalent-circuit cell model, an Extended Kalman Filter (EKF) for state-of-charge (SOC) estimation, and an active cell-balancing algorithm. Simulation results demonstrate EKF SOC estimation with a post-convergence mean absolute error (MAE) of 0.58% under a US06-equivalent drive cycle with 10 mV RMS measurement noise, recovering from a −15% initialization error within 69.5s; under identical conditions, standalone Coulomb counting exhibits 15.0% MAE. Active balancing recovers 3.2% additional usable pack capacity over passive balancing by cycle 100 in a 12-cell series string with ±3% capacity variation, rising to 4.7% under end-of-life imbalance, with a converter-efficiency sensitivity analysis quantifying the dependence on realistic converter losses. A threshold-based fault-detection layer identifies overvoltage, undervoltage, and thermal-runaway conditions within a single 100 ms control cycle. The modular architecture enables BMS algorithm development and fault-injection testing without physical hardware.
